# Trabajo practico semestral de data science
Este espacio corresponde al trabajo semestral de Diego Rojas y Benjamín Pinto. Se presenta el plan del trabajo y los avances de este.


## Contenidos
### I. Limpieza y procesamiento de datos de la estación meteorológica Quinta Normal
1. Importación de datos y librerias
2. Creación de columnas según fecha correspondiente al instante
3. Eliminación y renombre de columnas
4. Busqueda de datos nulos
5. Eliminación de datos según criterio por nulos

### II. Estadística descriptiva
1. Agrupación por mes de los datos
2. Análisis estadistico mensual de los datos
3. Agrupación por año de los datos
4. Análisis estadístico anual de los datos
5. Identificación de datos extremos por mes y año
